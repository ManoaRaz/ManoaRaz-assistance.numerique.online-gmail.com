Que comprend exactement le forfait ?

Le forfait couvre un site vitrine simple, la préparation ou amélioration des textes à partir des informations fournies, un SEO technique de base et la mise en ligne sur GitHub Pages.

Le nom de domaine est-il inclus ?

Non. Si vous possédez déjà un domaine, il peut être étudié pour le raccorder au site. Si vous n'en avez pas, vous pouvez utiliser l'adresse GitHub Pages gratuite ou acheter séparément un domaine personnalisé.

Puis-je envoyer mes propres images ?

Oui. Le formulaire accepte jusqu'à quatre images. Vous pouvez également nous transmettre d'autres éléments ensuite via WhatsApp si nécessaire.

Est-ce adapté à une boutique en ligne complexe ?

Le forfait concerne un site vitrine ou d'exposition simple. Une boutique avec paiement, espace client, base de données ou fonctions avancées demande un devis séparé.
