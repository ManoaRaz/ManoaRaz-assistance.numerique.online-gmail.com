## Mise en ligne GitHub Pages

1. Décompressez l’archive et remplacez les fichiers à la racine du dépôt GitHub ; n’envoyez pas seulement le ZIP.
2. Vérifiez dans Tally que le formulaire `yX2v5W` est publié et que les notifications e-mail sont activées.
3. Sur `site-vitrine.html`, effectuez **une vraie demande test** et vérifiez qu’elle apparaît dans Tally → Submissions, puis dans votre boîte e-mail.
4. Le contenu du formulaire est chargé par Internet depuis Tally ; il ne fonctionne pas hors connexion. Ne considérez pas la réception validée tant qu’un test réel n’a pas abouti.
