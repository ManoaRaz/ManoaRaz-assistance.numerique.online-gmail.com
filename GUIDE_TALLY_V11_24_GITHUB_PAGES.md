# CVMemoire — publier le formulaire Tally sur GitHub Pages

**Formulaire intégré :** CV Pro_Étudiant, ID `4aJjEd`.

## Mise en ligne
1. Téléchargez et décompressez le ZIP V11.24.
2. Ouvrez le dépôt GitHub qui héberge `cvmemoire.click`.
3. Remplacez les fichiers HTML/CSS du dépôt par ceux du ZIP, en conservant les chemins et le dossier `jeu/`.
4. Attendez le déploiement GitHub Pages et actualisez la page (`Ctrl + F5`).
5. Sur `cv-gratuit.html` et `cv-accompagnement.html`, contrôlez que le formulaire Tally est visible **sur le site**.
6. Faites un test de demande avec une petite pièce jointe, sans données privées réelles.
7. Dans Tally, ouvrez **Submissions** et vérifiez l’apparition de cette demande.
8. Dans Tally, activez les notifications e-mail au propriétaire du formulaire et testez la réception dans Gmail et dans les spams.

**Attention :** l’intégration HTML ne suffit pas à prouver que les notifications Gmail sont activées. Ne relancez pas de publicités avant ce test réel.

## Ce qui change
- Le même formulaire est directement intégré sur les deux pages CV.
- La page CV gratuit conserve son outil de prévisualisation/export PDF dans une section facultative, indépendante de Tally. Les champs de cet outil ne se transfèrent pas automatiquement vers Tally.
- Les autres formulaires de services (mémoire, conversion PDF, sites vitrines, etc.) ne sont **pas** migrés : ils ont besoin de leurs propres formulaires Tally ou d’une autre API externe.
- Les fichiers du jeu ANGAYA CRUSH sont strictement inchangés.

Le formulaire Tally peut être modifié depuis le compte Tally ; les changements des champs paraîtront sur CVMemoire sans devoir ré-uploader le code, tant que l’identifiant du formulaire ne change pas.
