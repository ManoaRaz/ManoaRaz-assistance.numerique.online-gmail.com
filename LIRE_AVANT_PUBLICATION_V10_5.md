# CVMemoire V10.5 — menu épuré

## Navigation principale
Sept liens seulement, identiques sur les 14 pages : Accueil, Créer un CV, Mémoire, Traduction, PDF, eBooks IA, Sites web.

Les rubriques Professionnels, Tous les services, Informations et CV accompagné ne sont plus affichées dans le menu principal. Leurs pages **restent en ligne** : elles sont accessibles depuis les cartes de l’accueil, la page CV et/ou le pied de page.

La confidentialité reste accessible en un clic via **Confidentialité**, dans le pied de page de toutes les pages, ainsi que depuis les formulaires lorsque pertinent. Les conditions d’utilisation et les mentions légales restent accessibles également.

Le bandeau d’en-tête est désormais sur **une seule ligne** sur ordinateur et un bouton Menu sur mobile (7 liens verticaux). Le bouton « Créer mon CV » qui doublonnait avec la rubrique CV est retiré du bandeau.

Tous les formulaires, API et scripts publicitaires d’origine sont laissés en place.

## Publication
Conserver le dossier `assets` et les fichiers `app.js`, `api/`, HTML et CSS. Tester sur un environnement de préproduction puis mettre en ligne l’ensemble du dossier. Purger le cache CDN et actualiser le navigateur. Ne pas modifier directement les fichiers de la V10.4 si vous voulez conserver un retour arrière.

Cette refonte **ne publie pas automatiquement** le site et ne garantit pas la conformité légale des services proposés.
