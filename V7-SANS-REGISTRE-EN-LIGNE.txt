CVMEMOIRE.CLICK — V7 SANS REGISTRE EN LIGNE

Cette version ne contient plus de mémoire/registre en ligne des demandes.

Supprimé :
- stockage GitHub des requêtes ;
- base/mémoire centralisée des formulaires ;
- page administrateur memoire-demandes.html ;
- API de lecture/export/suppression ;
- authentification administrateur liée à ce registre ;
- suivi des téléchargements d'eBooks ;
- suivi serveur des traductions.

Les formulaires CV / mémoire / conversion :
- sont transmis directement au WhatsApp administrateur configuré ;
- ne créent pas de copie structurée supplémentaire dans GitHub ou une base CVMemoire.
