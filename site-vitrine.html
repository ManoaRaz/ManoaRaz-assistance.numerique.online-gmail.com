Que comprend exactement le forfait ?

Pour 50 000 Ar : création d’un site vitrine simple, amélioration des textes, SEO de base, bouton WhatsApp Click-to-Chat, mise en ligne sur GitHub Pages si éligible et enregistrement d’un nom de domaine .click standard pour la première année.

Le nom de domaine est-il inclus ?

Oui : un domaine standard en .click, comme monsite.click, est inclus la première année, sous réserve de disponibilité et de confirmation du nom. Les noms premium et autres extensions sont exclus ; le renouvellement annuel après la première année reste à votre charge.

Quelle intégration WhatsApp est prévue ?

Le site inclut un bouton qui ouvre directement une conversation sur WhatsApp via Click-to-Chat. Les chatbots et l’API officielle WhatsApp Business Cloud pour messages automatisés ne sont pas inclus.

Comment fonctionne l’hébergement GitHub ?

La publication sur GitHub Pages est prévue pour un site statique compatible avec les conditions d’utilisation de GitHub. Si le projet ne répond pas à ces conditions ou nécessite un serveur, une autre solution d’hébergement sera convenue avant réalisation.

Puis-je envoyer mes propres images ?

Oui. Le formulaire accepte jusqu'à quatre images. Vous pouvez également nous transmettre d'autres éléments ensuite via WhatsApp si nécessaire.

Est-ce adapté à une boutique en ligne complexe ?

Le forfait concerne un site vitrine ou d'exposition simple. Une boutique avec paiement, espace client, base de données ou fonctions avancées demande un devis séparé.
